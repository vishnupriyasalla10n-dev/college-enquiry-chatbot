#  College Enquiry Chatbot

# About the Project

The College Enquiry Chatbot is a web-based application designed to help students get college-related information easily. Students can ask questions and receive answers through a chatbot with voice input and voice output features.

# Features

- User Registration
- User Login
- College Enquiry Chatbot
- Voice Input using Microphone
- Voice Output for Chatbot Responses
- Scholarship Information
- Clear Chat Option

# Technologies Used

- HTML
- CSS
- JavaScript
- Web Speech API

# How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `login.html`.
5. Right-click and select **Open with Live Server**.
6. Register or log in to use the chatbot.

 # Project Objective

The main objective of this project is to provide students with quick and easy access to college-related information through a simple and interactive chatbot.
